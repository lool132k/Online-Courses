# Продвижение 09–10.11.2026 · аккаунт и HTML-каталог

## Результат

- Каталог `/demo/index.html` показывает гостю вход и регистрацию, пользователю с сессией — имя, кабинет и выход. При возвращении во вкладку данные обновляются. Имена вставляются через textContent, токены не доступны JavaScript каталога.
- В кабинете можно изменить имя (2–80 символов). Сервер принимает только поле name, проверяет Origin и определяет пользователя по сессии, а не по переданному id.
- Применена облачная миграция `allow_own_profile_name_update`, локальный файл `supabase/migrations/202611090001_profile_name.sql`. PostgreSQL разрешает только UPDATE(name), RLS ограничивает изменение своим активным подтверждённым профилем. Роли и blocked остаются недоступны для изменения.
- При открытии HTML через file:// показывается адрес серверной версии. Ошибка аккаунта не блокирует демонстрационные курсы. Прогресс демокурсов по-прежнему локальный и не относится к конкретному аккаунту.
- Supabase найден INACTIVE и восстановлен до ACTIVE_HEALTHY. Временный Next.js-сервер после проверок остановлен.

## Проверено

- `npm test`: 6/6; в том числе нормализация имени, неверные типы, границы и запрет подстановки id/is_admin/blocked.
- `npm run typecheck`, `npm run build`, `node --check dist/account.js`: pass.
- `tests/auth-rls.sql` выполнен на облачной БД с rollback фикстур: своё имя изменяется; чужое, недопустимое, неподтверждённое и заблокированное — нет; изменения ролей и чужой доступ запрещены; повторная pending отклонена.
- HTTP PATCH: чужой Origin — 403; is_admin в теле — 400; короткое имя — 400; валидное тело без сессии — 401.
- Браузер, временный тестовый аккаунт: каталог → вход → кабинет → изменение имени → перезагрузка → каталог с новым именем → выход → недоступный профиль. Значение имени отдельно подтверждено SELECT из profiles; роли остались false.
- Шапка на 360 px: элементы видны, document.scrollWidth = clientWidth = 345 (оставшаяся ширина занята полосой прокрутки).
- Скриншоты: `docs/screenshots/2026-11-09/` (использован только синтетический тестовый аккаунт).
