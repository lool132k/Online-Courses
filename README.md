# BMBCourses

Учебная платформа бесплатных онлайн-курсов.

Сайт: https://names-online-courses.onrender.com

## Запуск

npm ci, заполнить .env.local по .env.example, затем npm run dev. Для production: npm run build и npm start.

APP_URL должен совпадать с origin сайта. Supabase URL и publishable key хранятся в окружении. Секреты не коммитятся.

## Обучение и управление курсами

Регистрация, подтверждение почты, повторное письмо, вход в каталог, профиль, заявка преподавателя, локальный выход и выход на всех устройствах. Восстановление пароля использует отдельный recovery callback и одноразовый токен. Gmail SMTP подключён.

- `/courses` — опубликованные курсы, поиск, совместные фильтры и страницы по 12 курсов. Каждая карточка имеет собственный URL. Гостю доступна программа без текстов уроков.
- `/account` → «Мои курсы» — записи, продолжение обучения, прогресс из PostgreSQL, отписка и восстановление. Повторная запись сохраняет учебную версию курса. Прогресс HTML-демо хранится отдельно в браузере.
- `/account` → «Результаты» — число завершённых курсов и пройденных квизов, средний балл по лучшим попыткам и история квизов.
- `/learn/<id>` — последовательное прохождение уроков, видео YouTube/Vimeo, временные ссылки на закрытые материалы и квизы с серверной оценкой. Ссылка с `?lesson=2` открывает конкретный урок после проверки доступа.
- При кратком обрыве связи квиз повторяет сохранение ответа, пока открыт урок и действует попытка. Интерфейс подтверждает сохранение после ответа сервера.
- `/studio` — редактор курсов, модерация и обработка заявок преподавателей. Автор видит результаты студентов своего курса. Каждая публикация фиксирует новую версию.

Вход ограничен по адресу и IP, счётчики переживают перезапуск сервера. Сеанс действует до 7 дней и должен существовать в auth.sessions: отозванная cookie не даёт доступ к кабинету.

## Подключение и проверки

- [Актуальный отчёт, лимиты и ограничения](docs/PROGRESS_2026-11-20.md).
- [Настройки Supabase](docs/AUTH_SETUP.md): применить все миграции по порядку и установить recovery email template.
- npm test — модульные тесты. npm run build — проверка типов и production-сборка.
- tests/auth-rls.sql, tests/courses-security.sql и tests/learning.sql — проверки БД с rollback. Порядок обновления Render и миграций описан в [инструкции по развёртыванию](docs/RENDER_DEPLOY.md).
- tests/http-acceptance.mjs — интеграционный runner. Создание временного аккаунта и отправка писем требуют явного разрешения владельца. Тестовые пароли/токены передаются через stdin и не сохраняются.

## HTML-каталог

Через сервер используйте `/courses`. Старый адрес `/demo/index.html` перенаправляется в каталог. Отдельный `dist/index.html` можно открыть как файл с локальными демоданными.
