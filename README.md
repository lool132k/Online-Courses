# Онлайн курсы

Учебная платформа: преподаватели публикуют бесплатные курсы, студенты проходят уроки и тесты с сохранением прогресса.

## Серверная версия · Sprint 02

`npm ci`, заполнить `.env.local` по `.env.example`, затем `npm run dev` и открыть http://localhost:3000.
Подключение Supabase и обязательные настройки: [docs/AUTH_SETUP.md](docs/AUTH_SETUP.md).
Добавлены формы регистрации/входа, подтверждение email, серверные API, профиль и заявка преподавателя. Нужны настоящий проект Supabase и миграция; без них API возвращает 503. Полные AUTH/ROLE ещё не завершены.

Прошлая неделя, прототип: [docs/SPRINT_01_RESULT.md](docs/SPRINT_01_RESULT.md). Текущая неделя 24–30.10, регистрация и проверки: [docs/SPRINT_02.md](docs/SPRINT_02.md). Следующая неделя, завершение и приёмка: [docs/SPRINT_03.md](docs/SPRINT_03.md).

### Отдельный HTML-прототип

Откройте `dist/index.html` в браузере. Для одинакового поведения localStorage предпочтителен локальный HTTP-сервер: `python -m http.server 8000 --directory dist`, затем `http://localhost:8000`.

Есть адаптивная главная, поиск и совместные фильтры, описание курса, демонстрационная запись, последовательные текстовые уроки, прогресс, отписка и восстановление прогресса при повторной записи. Данные вымышленные, сохранение только в браузере. Нет настоящего входа, API, БД, загрузки материалов, серверных тестов или админки. Это прототип CAT/LEARN, не готовый MVP.
