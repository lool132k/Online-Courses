# BMBCourses

Учебная платформа бесплатных онлайн-курсов.

Сайт: https://names-online-courses.onrender.com/demo/index.html

## Запуск

npm ci, заполнить .env.local по .env.example, затем npm run dev. Для production: npm run build и npm start.

APP_URL должен совпадать с origin сайта. Supabase URL и publishable key хранятся в окружении. Секреты не коммитятся.

## Реализовано на 20.11.2026

Регистрация, подтверждение почты, повторное письмо, вход в каталог, профиль, заявка преподавателя, локальный выход и выход на всех устройствах. Восстановление пароля использует отдельный recovery callback и одноразовый токен. Gmail SMTP подключён.

Каталог и 12 уроков четырёх учебных курсов загружаются из PostgreSQL через /api/courses. RLS скрывает черновики и запрещает клиентское изменение курсов. Записи на курсы и учебный прогресс пока сохраняются в браузере. Создание/модерация курсов, видео, квизы и облачный прогресс остаются следующими этапами.

Вход ограничен по адресу и IP, счётчики переживают перезапуск сервера. Сеанс действует до 7 дней и должен существовать в auth.sessions: отозванная cookie не даёт доступ к кабинету.

## Подключение и проверки

- [Актуальный отчёт, лимиты и ограничения](docs/PROGRESS_2026-11-20.md).
- [Настройки Supabase](docs/AUTH_SETUP.md): применить все миграции по порядку и установить recovery email template.
- npm test — 9 модульных тестов. npm run build — проверка типов и production-сборка.
- tests/auth-rls.sql и tests/courses-security.sql — проверки БД с rollback.
- tests/http-acceptance.mjs — интеграционный runner. Создание временного аккаунта и отправка писем требуют явного разрешения владельца. Тестовые пароли/токены передаются через stdin и не сохраняются.

## HTML-каталог

Через сервер: /demo/index.html. Отдельный dist/index.html можно открыть как file://: он явно использует локальные демоданные. При ошибке облачного API серверный каталог показывает ошибку и кнопку повтора.
