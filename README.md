# Онлайн курсы

Учебная платформа: преподаватели публикуют бесплатные курсы, студенты проходят уроки и тесты с сохранением прогресса.

## Запуск первой версии

Откройте `dist/index.html` в браузере. Для одинакового поведения localStorage предпочтителен локальный HTTP-сервер: `python -m http.server 8000 --directory dist`, затем `http://localhost:8000`.

Есть адаптивная главная, поиск и совместные фильтры, описание курса, демонстрационная запись, последовательные текстовые уроки, прогресс, отписка и восстановление прогресса при повторной записи. Данные вымышленные, сохранение только в браузере. Нет настоящего входа, API, БД, загрузки материалов, серверных тестов или админки. Это прототип CAT/LEARN, не готовый MVP.

## Структура

- `docs/SPECIFICATION.md` — требования 2.0, целевая система.
- `docs/TRACEABILITY.md` — связь требований и карточек Trello.
- `tests/ACCEPTANCE.md` — сценарии ручной проверки.
- `docs/WEEKLY_REPORT.md` — план и честный статус.
